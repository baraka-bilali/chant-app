    Télécharger l’APK · 25 Mo

    Scannez pour télécharger Ouvrez l’appareil photo de votre téléphone Android et visez ce code.

    iPhone · Android · Ordinateur

    Version web installable (PWA)

    La même application, sans fichier à télécharger. Idéale pour iPhone.

    Ouvrir la version web

    Aucune installation requise

    Scannez pour ouvrir Fonctionne sur iPhone, Android et ordinateur.
    1. Ouvrez le lien dans Safari.
    2. Touchez le bouton Partager (le carré avec une flèche).
    3. Choisissez « Sur l’écran d’accueil », puis Ajouter.
    1. Ouvrez le lien dans Chrome.
    2. Touchez le menu ⋮ en haut à droite.
    3. Choisissez « Installer l’application ».
    1. Ouvrez le lien dans Chrome ou Edge.
    2. Cliquez sur l’icône Installer à droite de la barre d’adresse.
    3. Confirmez avec Installer.

    Ouvrez l’app une première fois avec internet : ensuite, elle fonctionne partout, même hors connexion.

    Questions fréquentes

    Vous avez une question ?

    L’application est-elle gratuite ?

    Oui, entièrement gratuite, sans publicité ni compte à créer.

    Faut-il internet pour lire les chants ?

    Non. Les chants sont dans l’application. Pour la version web, ouvrez-la une première fois avec internet : elle fonctionne ensuite hors connexion.

    Android me dit que l’installation est bloquée. Que faire ?

    C’est normal pour une application installée en dehors du Play Store. Touchez Paramètres dans le message d’Android et autorisez l’installation depuis votre navigateur, puis relancez l’installation.

    Comment l’installer sur iPhone ?

    Utilisez la version web : ouvrez-la dans Safari, touchez Partager, puis « Sur l’écran d’accueil ». Elle s’ouvre ensuite en plein écran comme une application.

    Mes playlists et favoris sont-ils sauvegardés ?

    Oui, ils sont enregistrés sur votre appareil. Ils ne sont pas partagés entre deux appareils différents.

    J’ai trouvé une faute dans un chant. Comment la signaler ?

    Écrivez-nous par WhatsApp ou par e-mail (voir plus bas) en indiquant le numéro du chant. Nous corrigerons au plus vite.
